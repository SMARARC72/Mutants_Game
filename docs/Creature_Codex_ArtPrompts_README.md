# Mutants_Game — Phase B ART PROMPT PACK (README)

**76 ready-to-paste prompts** covering all **660 net-new Phase B creatures**. Each prompt produces ONE style sheet of ≤10 creature designs. Built to stay on-model with your existing storybook/montage art.

## How to use

1. Open the file for the category you want and copy a single `### …` sheet's **PROMPT** block (everything from `STYLE` down through the numbered creatures).
2. Paste into your image generator. Each sheet yields ≤10 images in one grid.
3. **For best on-model results, attach one of your Phase A montages** (e.g. `art/montage_batch5_p1.png` or the storybook roster sheet) as a *style reference image* alongside the prompt — the design bible's image-reference approach keeps the canon look locked.
4. Wild-line & construct sheets group **complete evolution triads (baby→mid→apex)** so the three forms of a species render consistently. Generate a sheet, then crop/keep individuals as needed.
5. Sheet IDs map to codex IDs (e.g. WILD-S01 → WL001-1/-2/-3 …; GOD-S01 → OL-01…); cross-reference `Creature_Codex_Families.md` for lineage.

## The locked style anchor

STYLE (lock to the Mutants_Game canon — match the existing storybook/montage sheets): painterly digital illustration, mature-occult fantasy creature-design, full-body 3/4 view, characterful expressive faces, detailed but clean linework, rich slightly-desaturated palette, soft drop-shadow, on a warm off-white/parchment background. Funny-grim tone: each creature has an opinion and a body count — eerie but characterful, never gory, never generic. One single image: a clean numbered grid, each creature clearly separated, uniform lighting, sizes relative to power.

## Force → palette legend (keeps colors force-readable & consistent)

- **Gaia** (Bulk): earthen browns, stone-grey, moss-green; heavy rocky plating, roots, lichen, tusks
- **Ouranos** (Celerity): sky-blue, white, pale cyan, silver; aerodynamic, wind-curled fur/feathers, lightning glints
- **Cosmos** (Ward): white-gold, soft violet, pale azure; glowing ordered sigils, halos, crystalline facets, serene symmetry
- **Chaos** (Spike): ember red-orange, magenta, smoke-black; jagged asymmetric silhouette, glowing cracks, sparks

- **Thanatos** (Bane): violet-black, bone-white, sickly green; soul-flame wisps, exposed bone, tattered shroud, hollow glowing eyes

## Scale cues by rank/tier
- **T1 baby** small & cute-but-fanged · **T2 mid** spiky adolescent · **T3 apex** fully realized.
- **Legendary** imposing boss · **God** divine awe-scale · **Primordial** monumental pure-force embodiment · **Construct** built/mechanical (frame→engine→colossus).

## Per-creature line format
`N. **Name** (Force/Force · role · tier+stage) — body archetype; palette; scale cue. Vibe: "<authored hook>"`

_Each creature's identity (name, forces, role, stats) comes from the Codex; the `Vibe` line is its authored funny-grim description. Net-new only — Phase A (407) already has art._
