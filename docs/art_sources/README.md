# Tracked creature-art sources

This directory contains the small number of raw source plates that must remain reproducible but
do not belong to the gitignored bulk `art/` library. Runtime-ready 512 px flat and cutout variants
are generated by `tools/promote_creatures.py` into `client/assets/creatures/`.

| Source | Species | Origin | Notes |
|---|---|---|---|
| `creatures/batch5-023-zephrime-v2.png` | Zephrime (`batch5-023`) | OpenAI built-in image generation, 2026-07-11 | Replaces the original blank/truncated batch source. Prompt specified an Ouranos/Cosmos frost-rider striker on a clean warm off-white plate. |

Binary source plates are stored through Git LFS. Do not edit generated runtime plates by hand;
update the source, rerun promotion, and review the labeled QA sheets instead.
