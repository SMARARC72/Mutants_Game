# Mutants_Game — FRONT-END ART PROMPT PACK (Items · Tiles · Icons)

**23 ready-to-paste prompts → ~226 assets** for the game UX/UI. Each prompt yields ≤10 assets in one sheet. Built to sit alongside the creature art (same world, same palette).

## Files
- `Mutants_Game_UIArtPrompts_Icons.md` — force / stat / skill-verb / lab-verb / rank / class / acquisition / status glyphs.
- `Mutants_Game_UIArtPrompts_Items.md` — Lab parts & ingredients, consumables/mutagens/vials, soul essences, ritual & acquisition items.
- `Mutants_Game_UIArtPrompts_Tiles.md` — isometric world tiles, top-down grid tiles, and battle-scene backdrops.

## How to use
1. Copy one `### …` sheet's PROMPT block and paste into OpenAI image-gen. Each gives ≤10 assets.
2. **Items & icons:** ask for / keep TRANSPARENT backgrounds so they drop straight into inventory slots and the HUD.
3. **Tiles:** the prompts request SEAMLESS edges — generate, then test-tile; regenerate a single tile if a seam shows.
4. **Backdrops:** the sheet is for concepting; for production, regenerate any one backdrop alone at full 16:9.
5. **Stay on-model:** attach a creature montage (e.g. `art/montage_batch5_p1.png`) or a finished item as a style reference image with each prompt.
6. Force-coded assets follow the canon palette below so a Chaos vial always reads Chaos, etc.
