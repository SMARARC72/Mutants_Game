# MUTANTS_GAME — Game Loop & Session Flow (v0.1)

**Status:** roundtable-locked (orchestrated) · **Last updated:** 2026-06-27
**Principle:** *one tight loop you can run in fifteen minutes, wrapped in a campaign that ends in godhood, wrapped in a cycle that never really ends.*

---

## Core loop (moment-to-moment, ~5–15 min)

**Explore** the overworld → **Encounter** a wild creature or roaming rival → **Battle** (turn-based, AP, resonance, statuses, the entropy clock) → **Acquire** (catch/befriend) *or* **Defeat** (harvest Essence + parts) → **Lab / Husbandry** (breed · mutate · fuse · build · mod) → **Grow** (resonance awakenings, overclock gambles) → **Gear up** (loot) → **Compete** (arena/leagues) → **the world reacts** → repeat, climbing.

## Macro loop (the campaign — Acts 0–3)

Mortal → Demigod → Titan → God. Court factions, win competitions, **kill Olympians and reshape their regions**, build your team and Lab, harden your **morality grid** → the **final choice**: ascend (one of 9 grid-gods) · stay the God-Maker · the Unmaking.

## Meta loop (the Succession / NG+)

Finish → your champion becomes the **next run's world-boss** and your **friends' invader**. Each run authors part of the shared mythology. Carry-over: knowledge, select unlocks, the Graveyard, the registry.

## Onboarding (Act 0)

Threshold tutorial teaches **one system at a time** — first catch, first battle, first Lab op — then reveals the depth gradually. The premise (dead gods, empty thrones) and the High Table hook close the act.

## How it all interlocks (the through-line)

> **Forces** define stats → stats drive **battle** → battle yields **Essence/parts/loot** → that fuels the **Lab / husbandry / gear** → which makes stronger, stranger, one-of-one creatures → which win **competitions** and kill **gods** → which shifts **notoriety + the morality grid** → which makes the **world react** and factions move → which opens **ascension** → which seeds the **Succession** → which becomes the next run's wall.

Every system feeds two others; nothing is an island. The corruption/entropy meter is the shared cost; the soul-economy is the shared fuel; the force-vector is the shared language.

## Pacing & "always more"

Short loop stays moreish (explore→fight→catch/lab→grow). Long tail = breeding min-max, fusion discovery, registry completion, secret bosses, the 9 ascension paths, and friends' invasions. You can always go deeper, weirder, or darker.
