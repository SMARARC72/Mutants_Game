# MUTANTS_GAME — Vertical Slice: the Ruin Wolf line (v0.1)

**Status:** built & validated · **Reference:** `wire_line.py` · **Last updated:** 2026-06-27
**Principle:** *if one creature can flow through every system cleanly, the architecture is real.*

---

Taking a single registry creature (**Ruinmaw**, Chaos/Thanatos, the apex of the Ruin Wolf line) end-to-end through **all eight engines** in one pass:

```
[species]  Ruinmaw | Organic/Wild/T2 | Chaos/Thanatos | line: Ruin Wolf (pup SB30 -> Ruinmaw)
[stats]    one-of-one genome roll: Spike 97  Bane 92 ... | HP 333  BST 302
[leveling] 3 resonance awakenings -> expression 83% (Spike 81, Bane 76)
[lab]      FUSE Ruinmaw x Gloamcat -> Thanatos/Chaos chimera (entropy +15)
[skills]   Riot Fang, Soul Leech | SIGNATURE: Ruin's Hunger
[status]   inflicts Wither x2 -> -48 HP/tick
[loot]     wild catch @20% HP: 49% bare -> 66% geared
[world]    haunts the Mournmarch & the Sunder | Pale Court / Unbound
[ascend]   pure-Thanatos -> could seed 'The Devourer' via the Succession
```

**Result:** every system consumed the same creature and produced consistent, real numbers — because they all speak one language (**force-vector**), share one cost (**corruption/entropy**), and share one fuel (**essence**). The design isn't a pile of documents; it's one machine, proven on one beast.

## What this validates
Stat spine ↔ leveling ↔ Lab ↔ skills ↔ status ↔ loot ↔ world ↔ Succession all interlock with no glue-code contradictions. The remaining work is **content** (the 407 codex, the parallel session) and **tuning** (the balance pass), not architecture.
